# 買い物リスト

よく買うものを覚えてくれる、スマホ向けの買い物リストです。

**開く → https://duck6522-hue.github.io/shopping-list/**

- **リスト**: 「卵 2パック、牛乳、玉ねぎ×3」のようにまとめて入力。売り場ごとに自動で並びます
- **よく買う（メモリー）**: 買った回数と間隔を覚えて、「そろそろ」な品目をワンタップで追加
- **履歴**: 「買い物を完了」で日付・お店・合計金額つきで記録。過去の買い物をそのままリストに戻せます
- **端末ごとに保存**: データはその端末のブラウザ内（localStorage）だけに保存され、どこにも送信されません
- リストを文字やリンクで共有、バックアップの書き出し・読み込み、ダークテーマ、ホーム画面への追加（オフライン対応）

ビルド不要の静的サイトです（`index.html` ひとつ）。GitHub Pages で `main` ブランチのルートを公開してください。
